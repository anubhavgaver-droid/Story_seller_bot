# 🌟 sᴛᴏʀʏ sᴇʟʟᴇʀ ʙᴏᴛ

ᴀ ᴘʀᴇᴍɪᴜᴍ ᴛᴇʟᴇɢʀᴀᴍ ʙᴏᴛ ʙᴜɪʟᴛ ᴡɪᴛʜ ᴘʏʀᴏɢʀᴀᴍ ᴛᴏ ᴀᴜᴛᴏᴍᴀᴛᴇ ᴛʜᴇ sᴇʟʟɪɴɢ ᴀɴᴅ ᴅᴇʟɪᴠᴇʀʏ ᴏғ ᴀᴜᴅɪᴏ sᴛᴏʀɪᴇs. ɪᴛ ᴄᴏᴍᴇs ᴡɪᴛʜ ᴀ ғᴜʟʟʏ ғᴜɴᴄᴛɪᴏɴᴀʟ ᴡᴀʟʟᴇᴛ sʏsᴛᴇᴍ, ʀᴇғᴇʀ & ᴇᴀʀɴ ᴘʀᴏɢʀᴀᴍ, ᴀɴᴅ ᴀ sʟᴇᴇᴋ ᴍɪɴɪ ᴀᴘᴘ (ᴡᴇʙ ᴀᴘᴘ) ɪɴᴛᴇʀғᴀᴄᴇ ᴛᴏ ᴘʀᴏᴠɪᴅᴇ ᴜsᴇʀs ᴡɪᴛʜ ᴀ sᴇᴀᴍʟᴇss ᴘᴜʀᴄʜᴀsɪɴɢ ᴇxᴘᴇʀɪᴇɴᴄᴇ.

---

## 🚀 ғᴇᴀᴛᴜʀᴇs

* **📱 ᴍɪɴɪ ᴀᴘᴘ ɪɴᴛᴇɢʀᴀᴛɪᴏɴ:** ᴀ ʙᴜɪʟᴛ-ɪɴ ᴡᴇʙ ᴀᴘᴘ sᴛᴏʀᴇ ꜰᴏʀ ᴇᴀsʏ sᴛᴏʀʏ ʙʀᴏᴡsɪɴɢ ᴀɴᴅ ᴅɪʀᴇᴄᴛ ᴘᴜʀᴄʜᴀsᴇs.
* **💳 ᴡᴀʟʟᴇᴛ & ᴘᴀʏᴍᴇɴᴛs:** ɪɴ-ʙᴏᴛ ᴡᴀʟʟᴇᴛ ʙᴀʟᴀɴᴄᴇ ᴍᴀɴᴀɢᴇᴍᴇɴᴛ ᴀʟʟᴏᴡɪɴɢ ᴏɴᴇ-ᴄʟɪᴄᴋ ɪɴsᴛᴀɴᴛ ᴘᴜʀᴄʜᴀsᴇs.
* **📦 sᴍᴀʀᴛ ғɪʟᴇ ᴅᴇʟɪᴠᴇʀʏ:** ᴀᴜᴛᴏᴍᴀᴛɪᴄᴀʟʟʏ ғᴇᴛᴄʜᴇs ᴀɴᴅ ᴅᴇʟɪᴠᴇʀs ᴀᴜᴅɪᴏ/ᴠɪᴅᴇᴏ ᴇᴘɪsᴏᴅᴇs ғʀᴏᴍ ᴛʜᴇ ᴘʀɪᴠᴀᴛᴇ ᴅᴀᴛᴀʙᴀsᴇ ᴄʜᴀɴɴᴇʟ.
* **🔢 ᴄᴜsᴛᴏᴍ ʀᴀɴɢᴇ sᴇʟᴇᴄᴛɪᴏɴ:** ᴜsᴇʀs ᴄᴀɴ ʀᴇǫᴜᴇsᴛ sᴘᴇᴄɪғɪᴄ ᴇᴘɪsᴏᴅᴇs ʙʏ ᴘʀᴏᴠɪᴅɪɴɢ ᴀ ʀᴀɴɢᴇ (ᴇ.ɢ., `1-50`).
* **🎁 ʀᴇғᴇʀ & ᴇᴀʀɴ:** ᴀᴜᴛᴏᴍᴀᴛᴇᴅ ʙᴏɴᴜs sʏsᴛᴇᴍ ᴛᴏ ʙᴏᴏsᴛ ᴏʀɢᴀɴɪᴄ ɢʀᴏᴡᴛʜ.
* **📢 ʙʀᴏᴀᴅᴄᴀsᴛ ᴍᴀɴᴀɢᴇᴍᴇɴᴛ:** ᴇᴀsɪʟʏ ʙʀᴏᴀᴅᴄᴀsᴛ ᴍᴇssᴀɢᴇs ᴛᴏ ᴀʟʟ ʀᴇɢɪsᴛᴇʀᴇᴅ ᴜsᴇʀs ᴏʀ ʟɪɴᴋᴇᴅ ᴄʜᴀɴɴᴇʟs.
* **🧹 ᴀᴜᴛᴏ-ᴄʟᴇᴀɴ:** ᴀᴜᴛᴏ-ᴅᴇʟᴇᴛɪɴɢ "ᴅᴇᴍᴏ" ᴘʀᴇᴠɪᴇᴡs ᴀɴᴅ ᴀ ᴏɴᴇ-ᴄʟɪᴄᴋ "ᴄʟᴇᴀɴ ᴄʜᴀᴛ" ꜰᴇᴀᴛᴜʀᴇ ᴀғᴛᴇʀ ғɪʟᴇ ᴅᴇʟɪᴠᴇʀʏ.
